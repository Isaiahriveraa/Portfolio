# Portfolio

Professional developer portfolio for Yonie Isaiah Rivera-Aguilar.

## Tech Stack

- Next.js 14+ (App Router)
- React 18+
- TypeScript
- Tailwind CSS
- Framer Motion

## Features

- Dark theme with emerald green accents
- GitHub contribution graph
- Project showcase
- Responsive design
- Smooth animations

## Development

```bash
npm install
npm run dev
```
